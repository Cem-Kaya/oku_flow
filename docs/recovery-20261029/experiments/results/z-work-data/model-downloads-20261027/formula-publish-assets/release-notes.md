Optional native Math model sources for OkuFlow development. This is a model-data prerelease, not an application release.

FP32 ONNX encoder/decoder partitions of the pinned Apache-2.0 PaddlePaddle FormulaNet revisions. The app verifies exact hashes, builds hardware-specific TF32 TensorRT engines locally and activates only after compatibility checks. Original upstream configuration/model cards are downloaded from pinned Hugging Face revisions. Retain formula-pack-LICENSE.txt and formula-pack-NOTICE.txt with derived models.

No executable application or prebuilt TensorRT engine is distributed here.
