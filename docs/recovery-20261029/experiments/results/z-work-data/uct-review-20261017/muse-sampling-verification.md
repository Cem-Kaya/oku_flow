**4a Overflow — false on real paths.** Overflow needs 16,843,009 probe pixels. `SubmitProbe` caps probes at 960 wide ([controller](C:/Users/USER/AppData/Local/OkuFlow/worktrees/test-opt/src/app/ultra_clear_text_controller.cpp:423)), so 8K gives 960×540 (3% of the limit). The uncapped scheduler reference at decimation 2 ([ultra_clear_text.cpp](C:/Users/USER/AppData/Local/OkuFlow/worktrees/test-opt/src/common/ultra_clear_text.cpp:850)) gives 3840×2160 at 8K, still only 49% of `quint32` capacity. Overflow requires a ~16K viewport or a direct decimation-1 API call that no production caller makes. Optional fail-closed hardening is noted in the scratch file.

**4b Remainder/centroid drift — verified code defect, low impact.** `ow = width / decimation` floors ([ultra_clear_text.cpp](C:/Users/USER/AppData/Local/OkuFlow/worktrees/test-opt/src/common/ultra_clear_text.cpp:407)) while `SceneToViewPixel` maps by `ow`, giving an error of `u·(width mod decimation)` source pixels; even decimations ≥4 add a −0.5…−1.5 source-pixel centroid bias. It cancels at equal width and decimation (which refutes the `SceneSimilarity` claim) and is absorbed by the 6-probe-pixel search, but cross-decimation it reports a spurious offset — about 2.3 source pixels at `u=0.9` for width 1003, decimation 2 versus 4, on identical frames. The scratch file proposes storing `decimation` on `ProbeFrame` and mapping with the fractional `width/decimation`, plus that exact 1003-pixel regression.

**5 Decimation mismatch — plausible, needs reproduction; do not align yet.** The mismatch is real above 1920 wide, and `BoxAverage`'s 0.5 floor ([ultra_clear_text.cpp](C:/Users/USER/AppData/Local/OkuFlow/worktrees/test-opt/src/common/ultra_clear_text.cpp:54)) does widen the probe kernel when cells are about 1 reference pixel. But scene-area cells are the stated design for cross-zoom matching ([ultra_clear_text.cpp](C:/Users/USER/AppData/Local/OkuFlow/worktrees/test-opt/src/common/ultra_clear_text.cpp:49)), the dominant blur difference is the luma decimation itself, and Argon's `score > 0.99` oracle is unattainable by construction. The deciding test is small text (8–16 job pixels) at 2560 wide, reference decimation 2 versus probe 3, asserting the design threshold 0.82 — only if that fails should the per-job decimation floor be applied.
