OkuFlow now keeps current camera presentation responsive while optional neural work runs independently. This draft repairs the engineering audit's data-loss and ownership defects, adds an asynchronous Maxine producer, and develops Ultra Clear Text with configurable local OCR.

Recording and notes changes preserve failed/partial outputs, exclusive fallback files, elapsed audio gaps and exact recording/transcript identity. Observation, permission, operation and undo paths retain source/context/revision authority. USB advisory pressure, overdue native reads and reconnect completion use bounded queues and presented-video evidence. Build/bundle changes bind provenance to exact bytes and preserve atomic publication rollback.

Maxine loading, inference, completion and teardown belong to a private producer. Current-frame base/spatial presentation continues immediately; neural output can replace only its exact camera/frame/processing/settings ticket. Native edits revoke pending results and shutdown never joins a vendor call on UI.

Experimental UCT analyzes owned pre-zoom scene inputs, keeping 16x display zoom independent of recognition. TensorRT keeps neural preprocessing, detection, rectification, recognition and CTC on the GPU; independently configured ONNX Runtime CPU and built-in Windows OCR provide fallback. CPU serves while GPU engines prepare. Separate motion validation and cached scene-space glyph reprojection keep working while inference is slow. Padded recognition boxes fit source ink; replacement colors retain source backgrounds with bounded contrast adjustment and hysteresis. Busy presentation slots preserve only still-valid committed text.

UCT advanced settings now offer tiny/small/medium detector and recognizer choices independently for GPU and CPU. Defaults are GPU medium/medium and CPU tiny/small. The four preferences persist and share the existing full-catalog image-settings API, native controls, revision/user-wins checks and Stop and undo. Batch changes reload one OCR chain asynchronously. UCT activation remains off by default and session-only. Six immutable model/config/card pins and original notices stay outside automatic installer staging; startup/CMake never downloads models.
