# Intermediate native model-setup source

These are the text source revisions from nine historical source ZIPs that are
not otherwise reachable from the archived experiment heads or origin branches.
All other ZIP contents matched retained Git blobs, allowing redundant source
archives to be deleted. CRLF is normalized to LF for comparisons and storage.
The index records archive hashes and original paths. Identical blobs are stored
once. These are superseded prototypes, not patches approved for current main.
They retain exact research/build source context for the saved measurements.
