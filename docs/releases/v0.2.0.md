# OkuFlow 0.2.0

Download `OkuFlow-0.2.0-windows-x64.zip`, extract it, and open
`OkuFlow/oku_flow.exe`. Keep the DLLs and plugin folders beside the executable.
This Windows 10/11 x64 build includes the Qt runtime, licenses, SPDX inventory,
release manifest and SHA-256 checksums. The executable is unsigned; Windows
may show a SmartScreen prompt.

This release adds the OkuFlow Camera Android companion source and native USB
camera receiver, hardware H.264/H.265 negotiation with H.264 fallback, locally
discovered phone video modes and advanced phone settings. Existing USB webcams
remain supported. Saved camera choices take precedence; a ready companion is
preferred on first launch. Phone light starts off on each connection and has an
explicit button in Settings > Camera. Windows launches without a terminal;
`--console` attaches a parent terminal for diagnostics.

Transcription requires explicit opt-in in the Transcript tab and defaults off,
including during lecture recording. The release also contains the accumulated
settings recovery, recording, GPU pipeline, accessibility and UI fixes described
in [CHANGELOG.md](https://github.com/Cem-Kaya/oku_flow/blob/v0.2.0/CHANGELOG.md).

For phone capture, build/install the companion from
[android/](https://github.com/Cem-Kaya/oku_flow/tree/v0.2.0/android),
enable USB debugging, authorize the computer, and use an existing local Android
platform-tools adb server. APK and adb binaries are not included in this ZIP.
The companion currently supports Android 11/API 30 and newer. HEVC needs a phone
hardware encoder and an installed compatible Windows decoder; otherwise AVC is
used. Viewport-to-phone zoom handoff remains future work; Windows viewport zoom
continues to work.

Validation: release compilation; 24 CPU and 29 CUDA tests excluding GUI;
Android assembly, 49 JVM tests and lint; seven Python host tests; Windows
translation parity (747 keys) and Android parity (71 keys). The new Android build
was installed and streamed over USB on a Samsung SM-G780F running Android 13.
The owner reports completing Windows GUI testing and approved this tested build
for publication. The automated GUI suite was not run for this publication;
`OKUFLOW_SKIP_BUNDLE_TESTS=1` avoids repeating the bundle's full CTest gate.
