# Building OkuFlow Camera

OkuFlow Camera is the Android companion to OkuFlow. Use PowerShell 7 on Windows
11 and the checked-in Gradle wrapper. Android Studio is optional. No administrator
installation is needed. This scaffold uses AGP's built-in Kotlin support and the
Kotlin Compose compiler plugin; it does not apply `org.jetbrains.kotlin.android`.

```powershell
$env:OKUFLOW_ANDROID_JDK = "$env:LOCALAPPDATA\Programs\jdk-21"
```

`local.properties` yourself; an existing file is deliberately preserved.

## Build, test, lint, install

From the repository root:

```powershell
pwsh -NoProfile -File scripts/build_android.ps1
pwsh -NoProfile -File scripts/build_android.ps1 -Lint
pwsh -NoProfile -File scripts/build_android.ps1 -Install
```

Every invocation first checks exact English/Turkish/German Android resource
key parity (including duplicates and empty catalogs), then runs
`:app:assembleDebug :app:testDebugUnitTest`.
`-Lint` additionally runs `:app:lintDebug`. Errors return a nonzero process
exit code. Success prints the debug APK path:

```text
%LOCALAPPDATA%\OkuFlow\android-build\app\outputs\apk\debug\app-debug.apk
```

`-Install` uses `%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe` explicitly
(or the selected `ANDROID_HOME`). It installs with `adb install -r` and launches
`com.okuflow.camera/.MainActivity` only when one device is attached and authorized
and no other devices are attached. Zero, unauthorized, offline, or multiple
devices produce a clear skip message. Enable USB debugging and authorize the
computer on the phone first. No physical phone was present during setup.

### adb coexistence

The machine also has scrcpy's adb **37.0.0-14910828** on PATH and the old
Visual Studio SDK's adb **34.0.5-10900879**. The existing server belongs to scrcpy.
The new SDK adb **37.0.1-15733141** and scrcpy adb report protocol **1.0.41**.
Use the new SDK adb explicitly in OkuFlow scripts rather than whichever adb
PATH happens to select. Align scrcpy to the same SDK adb when needed using
scrcpy's documented `ADB` environment override in its own launch process.

The script never calls `adb kill-server` or terminates adb processes. Before
listing devices, it reads `host:version` directly from port 5037 and refuses
an incompatible protocol, because an ordinary adb command can automatically
restart an incompatible server. Custom adb endpoint environment variables are
rejected by `-Install` so this guard cannot silently inspect the wrong server.
If it refuses a server, close its owning tool yourself before retrying.

## Local outputs and Android Studio

The checkout is on Google Drive's virtual Y: drive. Generated files and caches
must remain local to avoid slow synced I/O and cloud uploads. Every Gradle
project's `layout.buildDirectory` is
`%LOCALAPPDATA%\OkuFlow\android-build\<project-name>`; the root project uses
`OkuFlowCamera`, and the app uses `app`. `OKUFLOW_ANDROID_BUILD_DIR` overrides
the common root and must be an absolute local path outside the checkout.
The build script passes `--project-cache-dir <root>\project-cache` and
`-Pkotlin.project.persistent.dir=<root>\kotlin-persistent`. The settings file
also supplies the Kotlin location for IDE sync, and Kotlin writes to the
Gradle project directory are disabled. Dependency/distribution caches use
Gradle's normal `%USERPROFILE%\.gradle` directory, which is outside Y:.
Gradle file-system watching is disabled on this virtual drive; otherwise it
writes a `.gradle/file-system.probe` under the checkout even with a relocated
project cache.

Unit-test reports are under `<root>\app\reports\tests\testDebugUnitTest`;
lint reports are under `<root>\app\reports\lint-results-debug.html` and `.xml`.

To use Android Studio, install a stable version supporting AGP 9.4 and open
the repository's `android` directory. Select the SDK path above and set
**Settings > Build, Execution, Deployment > Build Tools > Gradle > Gradle JDK**
to `%LOCALAPPDATA%\Programs\jdk-21`. Use the checked-in wrapper.
Before the first sync, put the expanded absolute local project cache path in
the IDE's Gradle invocation arguments as
`--project-cache-dir C:\...\OkuFlow\android-build\project-cache` (use expanded
absolute paths). If your IDE version does not expose sync arguments, launch it
from a shell with
`$env:JAVA_TOOL_OPTIONS = '-Dorg.gradle.projectcachedir=C:/.../OkuFlow/android-build/project-cache'`
set for that launch process, then restore the shell variable. This uses Gradle's
supported project-cache system property without changing user-wide configuration.
Run the PowerShell script in its terminal for the verified build workflow.
Direct wrapper invocations must likewise supply `--project-cache-dir` and
`-Pkotlin.project.persistent.dir` with expanded local paths; do not rely on
the wrapper's default project cache under the synced checkout.

## Licenses and removal

The streaming receiver has an independent standard-library probe/test suite:

```powershell
python -B -m unittest discover -s android/tests -v
python -B scripts/android_camera_probe.py --list
```

Use a Python 3.10+ interpreter. Probe recordings default to local app data;
`-B` prevents Python cache files in the synced checkout. The Android build
does not require Python. Phone code changes use the Android build/test/lint
script; native receiver changes also require the tracked Windows matrix.
See [`PROTOCOL.md`](PROTOCOL.md) for wire limits and [`README.md`](README.md)
for USB capture, settings and real-device acceptance.

AndroidX/Compose, Kotlin, AGP, and the generated Gradle wrapper use Apache-2.0
licenses. JUnit 4 uses EPL-1.0; its Hamcrest dependency uses BSD-3-Clause.
The dependency list is recorded in the repository's
[`docs/THIRD_PARTY_LICENSES.md`](../docs/THIRD_PARTY_LICENSES.md). Keep exact
resolved runtime notices and inventory when packaging a release APK.
The separately installed JDK uses GPL-2.0 with the Classpath exception; SDK/NDK
tools are governed by their installed vendor notices/licenses. They are not
bundled into the Windows release.

To undo this setup, clear the user variable with
`[Environment]::SetEnvironmentVariable('ANDROID_HOME', $null, 'User')` and
remove the newly installed `%LOCALAPPDATA%\Programs\jdk-21` and
`%LOCALAPPDATA%\Android\Sdk` directories once no tool is using them.
`%LOCALAPPDATA%\OkuFlow\android-build` contains only this app's generated
outputs/caches; `%LOCALAPPDATA%\OkuFlow\android-setup` contains installation
archives, checksum metadata, the bootstrap tools/distribution, and validation
logs. Both can be removed when no build is running. Gradle and Android also
create user caches under `%USERPROFILE%\.gradle` and `%USERPROFILE%\.android`;
remove only this setup's entries if other tools use those directories. Deleting
`android/local.properties` removes the checkout's machine-specific SDK path.
No persistent Java or PATH change needs undoing. The existing Android debug
signing key was reused without modification; do not remove it as part of this
setup's cleanup.
